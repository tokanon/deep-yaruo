# DeepAA 500作品の質的レビュー

## 結論

DeepAA由来の500作品は、**歴史的ベースラインと局所的なAA表現の事前学習には使えるが、Yaruo AA Studioの本番教師コーパスには採用しません**。作品単体には完成度の高い人物・メカAAがあります。しかし、集合全体が現在の目標である「元画像から、やる夫スレで修正・利用できる人物・背景AAを作る」用途を代表していません。

2017年のデータであることだけが不採用理由ではありません。MS PGothic系の12pt・Shift-JIS AAという表示条件と基本的な作字技法は、現在の対象用途にも残っています。問題は、年代以上に選定範囲、題材の偏り、品質の混在、元画像との対応欠如です。

## 確認方法

`datasets/bootstrap/deepaa-500.csv` の全500作品をSaitamaar 16px・18px行ピッチで再構成し、5系列・27枚のコンタクトシートとして全件を目視しました。

```powershell
.\.venv\Scripts\python.exe -m training.reconstruct_dataset `
  --output .tmp\reconstructed-quality-audit

.\.venv\Scripts\python.exe -m training.prepare_quality_review
```

レビュー補助ツールは `.tmp/bootstrap-quality-review/sheets/` にコンタクトシートを、同フォルダの `review.csv` に全500件の採点欄を生成します。CSVを再生成しても既存の `subject`、`quality`、`usable_for`、`notes` は保持します。

## 観察結果

### 系列と題材

| 系列 | 作品数 | 全体比 | 目視した主な内容 | 本プロジェクトでの扱い |
| --- | ---: | ---: | --- | --- |
| HM | 210 | 42.0% | アニメ人物、顔、立ち絵、複数人、ネタAA | 人物部品の候補。品質差が大きく要選別 |
| NoTone | 208 | 41.6% | アニメ人物、顔アップ、立ち絵、デフォルメ | 人物部品の候補。単純顔・小断片も混在 |
| UltraRobot | 56 | 11.2% | ロボット、武器、メカ | 直線・機械部品用。本番人物分布には混ぜない |
| UltraOther | 20 | 4.0% | 人物、機械、小型ネタAA、物体 | 異質な混合集合。個別判定が必要 |
| Hachi | 6 | 1.2% | 人物顔・上半身 | 件数が少なく系列評価不能 |

HMとNoToneだけで418作品、全体の83.6%です。背景・建築・室内・街路・自然景観は、500作品を通覧しても独立カテゴリとして成立する量がありません。したがって、このコーパスから背景生成能力を学習したと主張することはできません。

### 作品品質

良い作品には次の価値があります。

- 人が選んだ文字で曲線、髪、目、口、衣服、メカの輪郭を組み立てている。
- 可変幅文字と空白を使った位置合わせ、線の継ぎ方、局所的なデフォルメを含む。
- 人物顔やメカの一部には、現在も参照に使える完成度がある。

一方、教師集合としては次の問題があります。

- 完成度の高いAA、単純な顔文字、小型断片、台詞・看板を含むネタAAが同じ正解として混在する。
- 同じ系列の顔、髪、線の置き方が繰り返され、現代の多様な作風を代表しない。
- 人物の顔・上半身へ偏り、手、複雑なポーズ、複数人物、背景構造の網羅性が低い。
- ロボット56作品の規則的な直線・装甲表現が、人物・背景モデルの文字頻度を歪める。
- 完全重複作品が1組あり、CSV行の36.283%は完全重複している。

## 最大の不足: 元画像との対応がない

この500作品には、AA化する前のイラストや、作者がどの線を残しどの細部を捨てたかを示す対応画像がありません。AAをSaitamaarで描画した画像から同じAAを学習すると、文字の再認識や局所字形の学習にはなりますが、次は学べません。

- 精緻な元絵をどの程度デフォルメするか。
- 目、口、輪郭、髪、手、背景のどれを優先するか。
- 密集線を代表線へ置き換える判断。
- 元絵にはない空白や文字配置を、AAとして読みやすく作る判断。

これは年代より重大です。本プロジェクトが必要とするのは「完成AAの数」だけでなく、元画像・疑似線画・完成AA・人の評価が対応したデータです。

## 利用方針

| 用途 | 判定 | 理由 |
| --- | --- | --- |
| DeepAA学習済みモデルの再現 | 維持 | 既存ベースラインとの比較に必要 |
| 411文字の初期候補確率 | 補助限定 | 局所字形の候補生成には使える |
| AA文字列・部品の事前分布 | 選別後に利用 | 良質作品と用途別部品だけを抽出する |
| 人物・背景の最終教師 | 不採用 | 背景不足、品質混在、元画像対がない |
| validation・test | 不採用 | 5系列しかなく、現代の目標品質を表さない |
| 新モデルの品質根拠 | 不採用 | この500作品内の精度は実用AA品質を保証しない |

DeepAA派生モデルは削除せず「古いが再現可能な初期案生成器」として隔離します。今後の品質改善がDeepAAを上回るか確認する比較対象であり、最終到達点ではありません。

## 個別採点基準

全500作品を今後そのまま一括使用せず、レビューCSVで次の段階へ分けます。

- **A / AA単体採用候補**: 構図が明確で、重要線が連続し、文字選択とデフォルメに学ぶ価値があり、対象表示で崩れない。元画像対がないため、Aでもgold対にはしない。
- **B / 部品・事前分布用**: 全体教師には弱いが、目、口、髪、手、衣服、曲線、メカなど特定部品に価値がある。
- **C / 歴史的ベースライン限定**: 読めるが単純、作風が古い、題材が用途外、または局所的な癖が強い。
- **D / 除外**: 断片、重複、崩れ、文字ノイズ、台詞依存、対象不明、教師にすると悪影響が大きい。

採点時には `subject` を人物顔、人物上半身、人物全身、複数人物、背景、建築、自然、メカ、物体、ネタ・文字中心へ分けます。最終学習ではAを中心にし、Bは用途別候補や部品検索へ限定し、C・Dは本番教師から外します。

## 次に集めるデータ

最初から作品数を500へ固定しません。まず、現在目標とする品質のAAを作者・系列が偏らないよう100作品集め、出典、作者、年代、題材、表示条件、権利、品質評点を記録します。人物だけでなく背景・建築・室内・自然を独立カテゴリとして確保します。

weak-v1/v2では、線と塗りを1枚へ押し込んだ疑似入力を評価しましたが、字形を消すほど構造と塗りも失われたため、この単一画像経路は終了しました。その後、`E`の構造代理画像を線ch0、AAラスタ濃度をch1へ分離したP6 C2も実測し、合成testの改善に対して実画像で誤塗りしたため不採用としました。今後はAA本文の反復runを二次元の出力側塗り面へまとめ、ユーザーが用意する実在または生成元画像から草案AAを作り、人が修正した直接対応対で実画像面との対応を評価します。50、100、200件の学習曲線は直接対応対でも測定し、旧500作品の件数だけを変える実験は品質判断の中心にしません。
