# P3 線1ch下流文字分類

実行日: 2026-08-26

> **現在の位置づけ:** P3は下流診断を完了した不採用実験です。生ラスタC1は4倍候補より良い比較基準として後続実験に使いましたが、実行時モデルや品質改善としては採用していません。

## 目的

P2のドメインAUCと芯線Chamferだけでは、情報を消した候補を誤って有利と判定する可能性があります。P3では`accepted-v1`の正解AA本文を使い、構造代理画像`E`を共通`X`の線`ch0`へ通した後、正しい文字を分類できるかを比較します。

これは合成往復データ上の下流有用性であり、正解AAのない実画像に対する最終品質ではありません。

## データセット

- 作品: `accepted-v1`の採用100作品
- split: source MLTをまたがないtrain 80、validation 10、test 10
- 411語彙内の文字例: 226,146
- train: 186,687例
- validation: 17,033例
- test: 22,426例
- 元本文の全227,095文字に対する411語彙被覆率: 99.582%
- 語彙外: 949文字
- 512px幅への正規化後に同じ開始座標へ潰れた例: 0

各AAをSaitamaar 16px・18px行送りで描画し、P2と同じ`raw_raster`または`supersampled_blur_downsample`を作り、共通`X`の`ch0`だけを64×64文脈分類へ渡します。正解文字位置はSaitamaarの実advanceを元キャンバスから512px座標へ変換して作ります。

## 学習条件

| 項目 | 値 |
| --- | --- |
| 初期重み | `models/deepaa-light.onnx`をPyTorchへ数値移植 |
| 構造 | DeepAA light準拠4層CNN、411クラス文字head |
| 入力 | `1×64×64`、線`ch0`のみ |
| optimizer | AdamW |
| learning rate | 0.0001 |
| weight decay | 0.0001 |
| batch size | 256 |
| epochs | 6 |
| seed | 42 |
| device | CUDA |
| augmentation | なし。`E`候補そのものの差を比較するため固定 |
| checkpoint選択 | validation loss最小 |

生ラスタはepoch 5、4倍候補はepoch 6が選ばれました。両条件は同じ初期重み、文字順、split、seedを使います。

## 固定test結果

| 指標 | 生ラスタ | 4倍描画・ブラー・縮小 | 4倍 − 生 |
| --- | ---: | ---: | ---: |
| 学習前accuracy | 43.13% | 41.42% | −1.71pt |
| 学習後accuracy | **57.41%** | 55.88% | −1.53pt |
| 学習後・非空白accuracy | **62.88%** | 60.44% | −2.44pt |
| 空白accuracy | 30.82% | **33.69%** | +2.87pt |
| Top-5 accuracy | **92.63%** | 91.70% | −0.93pt |
| test出現225クラスのmacro accuracy | **19.61%** | 16.20% | −3.41pt |

test 10作品を単位に2,000回paired bootstrapした結果は次のとおりです。

| 差 | 点推定 | 95%区間 |
| --- | ---: | ---: |
| 全体accuracy、4倍 − 生 | −1.53pt | −3.73～+0.63pt |
| 非空白accuracy、4倍 − 生 | −2.44pt | −5.33～+0.22pt |

区間は0をまたぐため、10作品だけから4倍候補が統計的に劣ると断定しません。ただし点推定、非空白、Top-5、macro、全頻度帯で4倍候補は生ラスタを上回りませんでした。

## 頻度帯別結果

頻度帯は旧DeepAAコーパス上の文字頻度で分けます。これは新コーパスの最終語彙しきい値ではありません。

| 旧頻度 | test例 | 生ラスタ | 4倍候補 |
| --- | ---: | ---: | ---: |
| 1000以上 | 20,445 | **61.28%** | 59.78% |
| 100～999 | 1,788 | **19.18%** | 17.11% |
| 20～99 | 163 | **2.45%** | 1.23% |
| 10～19 | 30 | 0.00% | 0.00% |

全体accuracyの大半は頻度1,000以上の文字が占めます。411語彙を維持しただけでは希少文字を学習できず、全体57%を実用文字分類の達成値とは扱えません。P0で決めた「全体・非空白・頻度帯を分ける」必要性が実測でも確認されました。

## 判断

- `raw_raster`をP4へ進むC=1基準として採用する。
- `supersampled_blur_downsample`はP2のAUCを0.01下げたものの、Chamferを平均0.919px悪化させ、P3の下流指標も改善しなかったため、暫定`E`混合から外す。コードと結果は比較基準として保持する。
- 4倍候補を永久に不可能と断定するのではなく、少なくとも現在のsigma 2.0px・4倍設定を採用しないという判断に限定する。
- P3の次はP4塗り段1へ進み、生ラスタC=1を境界・線の基準`M`として使う。
- 希少文字問題はP4の塗り処理と混同せず、語彙・sampling・loss比較の別課題として残す。

## 再現

学習専用環境から実行します。出力には第三者AA由来の画像、チェックポイント、評価が含まれるため`.tmp`からGitへ入れません。

```powershell
.\.venv-training\Scripts\python.exe -m training.train_structure_proxy_p3
```

既存出力を明示的に置き換える場合だけ`--force`を付けます。

```powershell
.\.venv-training\Scripts\python.exe -m training.train_structure_proxy_p3 --force
```

数値の正本は`.tmp/training-runs/structure-proxy-p3/report.json`、条件別のデータセットとチェックポイントは同フォルダの`datasets/`と`models/`です。
