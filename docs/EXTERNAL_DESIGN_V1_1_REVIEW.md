# 外部設計書 v1.1 検討結果

検討日: 2026-08-24

> **作成元と現在の位置づけ:** ここでいう「外部」はリポジトリ外から提示されたという意味であり、独立した第三者レビューを意味しない。元設計案、当時の検討、P0〜P6の実装・評価はいずれもAIアシスタントが作成した。2026-08-27の横断レビューにより、P6.1の`ch1`再校正を中止し、次工程を面単位へ変更した。現在の採否と停止条件は[P1〜P6 方向性レビューの採否](P1_P6_DIRECTION_REVIEW.md)を正とする。

## 結論

外部設計書に挙げられた技術案は、現時点で事前に不採用とするものはない。線・濃度・塗りの分離、`E`の混合セット、共通抽出器、段階ゲート、レンダラ逆検証、塗り段1〜3、デコーダ強化、DPO・報酬モデル、P9候補を、設計書の順序に沿って比較対象として保持する。個別候補の採否は各フェーズの実測後に決める。

ただし、外部設計書の「原画推定」という名称は採用しない。完成AAから失われた本当の元絵へ戻ることはできず、`E`が作るのは実入力の線チャンネルへ分布を近づけるための**構造代理画像**である。コードと新規資料では`structure proxy`として扱い、元画像、直接対応対、正解画像とは区別する。

weak-v1、weak-v2、線＋塗り合成の失敗だけを根拠に、この`E`経路まで不採用とした初回判断は誤りだった。過去実験は塗りを明示チャンネルとして保持せず、単一の疑似入力画像の見た目を比較したもので、外部設計書の`Eはch0だけ、ch1はAAラスタから直接、C=1→2→3、複数Eを混合`とは異なる。過去実験が棄却したのは実装済みの個別変換であり、提案された多チャンネル学習経路ではない。

## 採用する提案

| 提案 | 採用方法 |
| --- | --- |
| `structure`、`tone`、`fill`の分離 | 実入力から線、低周波濃度、暗部面を別チャンネルで生成する。出力AA側は同一濃淡文字の反復から補助ラベルを作る。 |
| 学習時・推論時の抽出処理共有 | 同じクロップ、リサイズ、線正規化、濃度量子化を共通関数で実行する。AAだけに適用する逆変換は共有処理とは見なさない。 |
| `C=1 → 2 → 3`の段階投入 | 線のみ、線＋濃度、線＋濃度＋塗りマスクを同じ固定評価で比較する。 |
| レンダラ逆検証 | 文字列、advance、行送りから再構成した配置と実レンダリングを照合し、最初の不一致文字を報告する。 |
| 頻度帯別評価 | 全体accuracyだけでなく、非空白、頻度帯、塗り文字、線文字を分ける。 |
| 実画像参照集合 | ドメイン差の診断用に人物・背景・原画・線画を層化して集める。正解AAがない画像は最終accuracyには使わない。 |
| ビーム、DP、FCN化 | 現行のBeam/Viterbi/開始位置モデルを基準に、全X位置の再利用と配置探索を改善する。 |
| 人手pairwise評価 | 実画像から生成した複数草案の選択と修正量を保存し、まず候補再順位付けへ使う。 |

## 過去の失敗実験との違い

| 実験 | 実際に行ったこと | 欠けていたもの |
| --- | --- | --- |
| weak-v1 | 細線化、輪郭、簡略化、ランダム部分欠落を1ch画像として比較 | 塗り保持の評価軸、独立toneチャンネル、下流モデル評価 |
| weak-v2 | 局所密度、粗密度、量子化、輪郭合成などを1ch画像として比較 | 線とtoneの独立入力、`E`混合、`C=1/2/3`学習 |
| 追加合成 | `dropout`線の下へ画像密度由来の塗りを合成 | AA本文上の反復塗り規則、正しい境界、学習による統合 |
| 外部設計v1.1 | `E`はch0のみ、ch1はAAラスタから直接、必要ならch2を追加し、複数`E`を混合して`M`を学習 | これから実測する対象 |

したがってweak-v1/v2の低評価は、外部設計v1.1の不採用根拠にはしない。ただし各旧方式の既知の破綻は候補設定と異常検出へ利用する。

## 採用方法と検証上の補足

以下は技術案の不採用条件ではない。設計書内の矛盾を解消し、実験結果を誤読しないための評価手順と用語上の補足である。

### 1. `E`の選定は二軸フィルタの後に下流評価を加える

AAから失われた元絵を復元することは目的にしない。`E`はAAラスタから線構造の代理画像を作る非一意な変換である。ドメイン判別AUCと芯線Chamferが良くても、その画像から正しい文字を学べるとは限らない。特に強い平滑化はAUCを下げながら条件情報を消せる。外部設計書も二軸化でこの問題を緩和しているが、下流タスクの有用性を保証しない。

このためP2の二軸パレートは候補削減に使い、最終的な混合セットはP3の`charAcc`、頻度帯別accuracy、塗り文字accuracyでも確認する。実画像・人手修正AA対ができた後は修正量と人手評価も加える。

```text
AA → R → E候補 → 共通X(ch0) ─┐
AA → R → 密度・塗り抽出(ch1/ch2) ├→ M学習 → synthetic charAcc
                                      │
実画像 → デフォルメ → 共通X ─────────┘→ 草案AA → 人手評価・修正量
```

実在・管理生成元画像では`E`由来だけに評価を閉じず、まず現行生成器とのA/Bと安全指標でsynthetic-to-real転移を確認する。人手修正AAの直接対応対は、正解対応なしでは原因を切り分けられない例だけの任意監査・補正とし、`E`学習開始の前提にはしない。

### 2. 最終AAは設計書どおり人手評価する

設計書は原則部分で、文字写像`B`はAAそのものを正解にして`charAcc`を計算できる一方、最終AAの品質は「実画像には正解AAが存在せず`charAcc`が計算できないため人間だけが判定できる」と明記している。この評価分離をそのまま採用する。

設計書§7.7末尾の「品質の最終判定は`charAcc`（実画像由来の検証セットに対して）」という一文は、同設計書の原則部分、§7.3の人手評価、P8と矛盾する。これは設計全体の方針とは解釈せず、次の区分に統一する。

- 往復・再構成データ: `charAcc`、頻度帯別accuracy。実装回帰と事前学習の指標。
- 実画像・修正AA対: 文字編集距離、行幅差、反復塗りの一致、修正操作数。
- 正解AAのない実画像: 人手A/B、認識、重要部位、線、塗り、修正見込み。
- `AUC_dom`: ドメイン差の診断。単独の合否ゲートにはしない。

### 3. 画素・幾何指標の扱いは設計書どおり採用する

設計書はSSIM、I2V、レンダリングIoUを最終品質の目的関数にせず、塗り内部の画素被覆と実装診断を例外にしている。この区別は妥当なので変更しない。局所字形一致、線方向、接続点、塗り被覆は補助コストまたは診断として使い、最終判定を人手評価に置く。

### 4. 塗り段1の後処理上書きをP4へ戻す

過去に失敗したのは、画像密度から意味上の塗りを推測し、欠落させた線と1枚へ合成する方式だった。設計書の段1は、`ch2`で塗り内部を限定し、境界セルでは`M`を尊重し、実コーパスから得た塗り文字を画素被覆で選ぶ。前の失敗だけではこの方式を棄却できない。

したがって設計書どおりP4で実装し、固定ケースで誤塗り、主要線欠落、黒髪・黒目の被覆を測る。許容範囲なら段1をそのまま採用し、足りない場合だけP6の`C=2/3`学習とP7の統合デコーダへ進む。

2026-08-26にP4を実行した結果、32条件中16条件で主要線損失2%以下、ch2外追加1%以下、線画の置換0を満たしました。しかし人物の暗い髪・服・背景を同じ`;`の水平帯として扱い、髪の流れと黒目を表現できなかったため、段1単独は不採用としました。これは提案を事前棄却したのではなく、設計書のゲートを実装・実測した結果です。実装と数値は[P4資料](FILL_STAGE1_P4.md)に固定し、P6比較用に保持します。

### 5. `DPO`は設計書どおりP8候補として残す

設計書自身がDPOをP8に置いており、直ちに実行する提案ではないため、順序変更の対象ではない。現行は局所分類器と探索デコーダなので、まず人手比較を候補報酬・再順位付けに使う。AA列に対する方策確率と参照方策を定義できた時点でDPOを比較し、定義できなければ報酬モデルまたはpairwise rankerを使用する。

| Phase | 内容 | ゲート |

| **P1** | 共通入力抽出`X`と実画像参照集合: 線、低周波濃度、任意の暗部面 | AA側と実画像側の最終正規化を共通実装にし、30〜50参照画像を層化して保存。 |
| **P2** | `E`候補とch0抽出器を二軸パレートで比較。まず生ラスタと4x描画・ブラー・縮小で一周 | AUCとChamferを画像単位で測り、破滅的失敗を確認。候補混合を暫定決定。 |
| **P3** | `C=1`で`M`を追試し、`E`候補の下流有用性を測る | synthetic `charAcc`、頻度帯別accuracy、画像単位splitを記録。 |

| **P6** | `C=2`、必要なら`C=3`で再学習 | 塗り文字・頻度帯別accuracyと実画像評価が`C=1`を上回る。 |
| **P7** | FCN化、DP、接続・n-gram、2D改善。P4で不足した場合は線・濃度を統合するデコーダも比較 | 人手評価と修正量を同時改善。 |
| **P8** | 修正対応対、pairwise報酬、候補再順位付け、能動選択 | 未評価候補に対する人の順位との一致がランダム基準を上回る。 |

## 直近の実装順

1. レンダラ・advance・ラベルの逆検証を追加する。
2. AA側と実画像側の線・低周波濃度・暗部面を返す`X`と、30〜50枚の実画像参照集合を作る。
3. `E`候補#0（生ラスタ）と#1（4x描画・ブラー・縮小）で、`X`、AUC、Chamferまでを一周させる。
4. `C=1`の下流`charAcc`を加えて、二軸だけで選んだ候補が実際に文字分類へ使えるか確認する。
5. 残りの`E`候補と混合セットを比較してから、`C=2/3`と二信号デコーダへ進む。

2026-08-26のP5では、生ラスタ50%と弱い描画劣化50%のch0混合が、Chamfer平均0.068px、test非空白文字精度差−0.048ptで保全ゲートを通りました。1px太線化は平均値では隠れた13.23pxの破綻を起こしたため除外しました。また従来ch1の等間隔4段階がAA側でほぼ全面0になることを検出し、量子化前gamma 0.5をP6候補へ追加しました。AUC低下が情報消失による場合を採用しないという補足が、実際に必要だったことを確認しています。詳細は[P5資料](STRUCTURE_AUGMENT_P5.md)に固定します。

2026-08-27のP6では、W48 C2が合成testの塗りrun内accuracyを+1.339pt改善しましたが、固定人物原画で反復塗りが19文字から2,428文字へ暴増しました。AA trainのch1は段階0/1、原画はほぼ段階2/3で、P5の平均使用段階数だけでは入力範囲外を検出できませんでした。広域toneを負例として混ぜるP6bは暴走を止めましたが、塗り改善と必要線を失いました。これはC=2案の事前棄却ではなく、設計どおり合成下流と実画像を両方測った結果です。現設定を不採用としました。

当初はC3前に共通toneを再校正するP6.1を予定しましたが、同日の横断レビューで、AA側の文字インク量と原画側の暗さという意味の不一致は値域調整では解消しないと判断しました。P6.1を中止し、次工程を面単位へ変更しています。現在の判断は[P1〜P6方向性レビュー](P1_P6_DIRECTION_REVIEW.md)を参照してください。
