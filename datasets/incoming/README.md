# Incoming datasets

Downloaded archives and generated extraction results belong under this directory and are ignored by Git. Keep only this README in the repository.

The Yaruyomi importer stores its source archive and generated files under `datasets/incoming/yaruyomi/<version>/`. Do not publish those files without a separate rights review.

Local reviewed snapshots such as `accepted-v1` and derived preference candidates such as `weak-v1` remain under the same ignored version directory. Their manifests preserve provenance but do not grant redistribution rights.
